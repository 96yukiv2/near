# これからの機能と確認

無料枠で進めます。有料契約やプラン変更が必要な場合は事前に知らせます。秘密情報はチャットに貼らず、サービス側に設定します。

## Web 版で先に進めること

1. **友達と位置共有**：招待・承認・削除・ブロックと位置共有は実装済み。テスト用アカウント同士で、申請から承認、共有・停止まで確認する。友達以外から位置を取得できないことは、公開前に API 権限テストで確認する。
2. **認証の仕上げ**：通常の Near ドメインでパスキー認証を設定済み。登録・ログイン・ログアウトを実機で確認し、Supabase の従来のメール・パスワード認証を無効化する。画面を隠すだけでは API を無効にできない。
3. **復旧**：メール確認と復旧コードの実装はあるが、メール送信サービスは未設定。Supabase 側の既存セッション・発行済みトークンを安全に失効させる対応と、無料の送信手段の設定・検証が終わるまで復旧は無効にする。
4. **アカウント削除**：削除処理は実装済みで、従来認証用 Edge Function は開発用 Supabase にデプロイ済み。パスキー利用者の認証データと位置情報の削除、途中失敗からの再試行を実環境で確認する。
5. **安全性とテスト**：CI の単体テストと API 権限テストは一時停止中。位置情報のアクセス制御は画面確認だけでは十分に検証できないため、実際の利用・公開前にテストを再開する。アクセス権限、無料枠、タイル提供元の利用条件も確認する。

## その後の画面とデザイン

- トップに Near の説明とログインへの入口を置き、マップは別画面にする。
- スマホで地図や友達を見やすく配置し、ログイン時の表示と操作感を整える。
- アイコンの変更を追加する。画像アップロードか用意されたアイコンから選ぶかは、保存する情報と費用も含めて決める。
- 現在の地図は OpenStreetMap の画像タイルを使用している。MapLibre は別の地図スタイルにも対応するため、無料枠・利用条件・帰属表示を確認してから、親しみやすい見た目を検討する。

## モバイルアプリ

Web 版の後に Expo アプリを検討する。バックグラウンド位置共有の OS 制限、Android のプレビュー配布、iOS の無料実機テストと有料配布をそれぞれ確認する。

実装・設定は AI が進め、サービスのアカウント作成や実機確認など AI ができない操作はユーザーにお願いする。認証の詳細は [パスキー認証](passkey-auth.md)、権限の設計は [設計](design.md) を参照。
