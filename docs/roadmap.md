# これからの機能と確認

無料枠で進めます。有料契約やプラン変更が必要な場合は事前に知らせます。秘密情報はチャットに貼らず、サービス側に設定します。

## 今回の Web 版

- **トップと地図**：トップに Near の説明とログイン・地図への入口を配置。地図の色味と画面を調整し、位置の一覧から名前を選ぶとその場所へ地図が移動する。共有停止・友達削除・ブロック後に取得できない権限は DB で制御する。
- **アイコン**：写真をアップロードせず、用意されたアイコンから選択する。表示名と一緒に保存し、承認済みの友達一覧と、位置の閲覧を許可された地図に表示する。アイコン用 DB マイグレーションは開発環境に反映済み。
- **費用と地図**：現在の OpenStreetMap 標準画像タイルの色味を調整している。新しい地図サービスの契約やキーは不要。標準タイルは可用性が保証されず、提供元の利用条件とアクセス量は公開前に確認する。

## 公開・実利用までの残作業

1. **友達・位置の権限確認**：2 人以上のテストアカウントで招待・承認・共有・停止・削除・ブロックを確認する。未ログイン、未承認、友達の友達、他人の位置更新を含む API 直接テストも実施する。CI では一時停止中。
2. **認証**：通常ドメインでの新規登録・ログインを実機で確認し、Supabase 側の従来メール・パスワード認証を無効にする。画面を隠すだけでは直接 API からの利用を止められない。LINE 内ブラウザと Safari の動作も確認する。
3. **アカウント復旧**：メール確認と復旧コードは実装済みだが、メール送信サービスは未設定。復旧後の Supabase セッション削除と、古いトークンを Near の API で拒否する対策を追加する。無料のメール送信手段の設定と実際の Supabase を使ったセキュリティ検証が完了するまで復旧機能は無効のままにする。
4. **削除**：パスキー認証側と Supabase 側の削除、位置・友達関係の削除、途中失敗後の再試行を実際のテストアカウントで確認する。
5. **地図とデザイン**：さまざまなスマホ幅で操作を確認し、地図やパネルの調整を続ける。写真アップロード方式のアイコンは未対応。別の地図スタイルを使う場合は無料枠、条件、帰属表示を再確認する。
6. **自動テスト**：CI の単体テストと API 権限テストは一時停止中。位置情報を友達以外に渡さないことは画面確認だけでは保証できないため、実利用前に権限テストを再開する。

## モバイルアプリ

Web 版の後に Expo アプリを検討する。バックグラウンド位置共有の OS 制限、Android のプレビュー配布、iOS の無料実機テストと有料配布をそれぞれ確認する。

実装・設定は AI が進め、サービスのアカウント作成や実機確認など AI ができない操作はユーザーにお願いする。認証の詳細は [パスキー認証](passkey-auth.md)、権限の設計は [設計](design.md) を参照。
